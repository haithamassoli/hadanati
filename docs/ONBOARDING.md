# دليل الإعداد السريع — Concierge Onboarding (≤ ساعة واحدة)

هذا هو دليل التشغيل الداخلي لإعداد حضانة جديدة على «حضانتي» (PRD §4).
شخص واحد من فريقنا + مكالمة واحدة مع مديرة الحضانة = حضانة تعمل بالكامل
مع رموز أولياء الأمور جاهزة للإرسال، خلال أقل من ساعة.

## المتطلبات قبل المكالمة

- صلاحية تشغيل دوال Convex على بيئة الإنتاج (`npx convex run --prod` من مجلد المشروع، أو من لوحة تحكم Convex).
- من الحضانة (اطلبها مسبقاً عبر واتساب/بريد):
  - اسم الحضانة الرسمي.
  - بريد إلكتروني وكلمة مرور لحساب المديرة (البريد **يجب ألا يكون مستخدماً من قبل** — الدالة ترفض البريد المكرر وتفشل قبل أي كتابة).
  - السنة الدراسية الحالية وتاريخا بدايتها ونهايتها.
  - قائمة المراحل والصفوف، وقائمة الطلاب لكل صف: الاسم بالعربية، تاريخ الميلاد `YYYY-MM-DD`، الجنس، اسم ولي الأمر، هاتفه، صلة القرابة. (جدول Google Sheets يفي بالغرض.)
  - قيمة القسط الأساسي ودوريته (شهري/فصلي/سنوي/مرة واحدة) — **بالفلس**: 85 دينار = `85000` فلس.
  - شعار الحضانة (صورة PNG/JPG) إن وُجد.

## الأمر الواحد

`admin:onboardNursery` هي `internalAction` تنشئ كل شيء دفعة واحدة:
الحضانة + حساب المديرة + المراحل + الصفوف + الطلاب (مع ولي الأمر، الموافقة
على الصور `false` افتراضياً) + تسجيلات السنة الفعّالة (مربوطة بخطة الرسوم إن
أُعطيت) + **رمز دخول لبوابة أولياء الأمور لكل طالب**.

### ماذا يُرجع الأمر

```json
{
  "nurseryId": "m97...",
  "codes": [
    { "studentNameAr": "ليان الخطيب", "code": "AB12-CD34-EF56" },
    { "studentNameAr": "عمر الزعبي",  "code": "GH78-IJ90-KL12" }
  ]
}
```

- **احفظ المخرجات فوراً** — الرموز تُعرض هنا مرة واحدة فقط (لا يُخزَّن إلا الـ hash).
- أرسل كل رمز لولي الأمر عبر واتساب بصيغة مثل:
  «رمز الدخول إلى بوابة حضانتي الخاص بالطالب ليان الخطيب: AB12-CD34-EF56 — افتح `https://<الدومين>/portal` وأدخل الرمز».
- ضاع رمز؟ المديرة تعيد إنشاءه بنفسها من صفحة الطالب (بطاقة «رمز ولي الأمر» → إعادة الإنشاء).

### تنبيهات

- الدالة **ليست idempotent**: إعادة التشغيل بنفس `adminEmail` تفشل قبل أي كتابة (بريد مكرر في نظام المصادقة). استخدم بريداً جديداً لإعادة المحاولة.
- سقف عملي: ~1500 طالب في الاستدعاء الواحد (كل طالب ≈ 3 كتابات ضمن حد 8K).
- المبالغ **دائماً بالفلس الصحيح** (`85.500` د.أ = `85500`) — لا كسور عشرية أبداً.

## المتابعات اليدوية بعد الأمر

بحساب المديرة الجديد على `/login`:

1. **الشعار**: الإعدادات → رفع شعار الحضانة.
2. **خطط الرسوم**: المالية → الخطط — تأكد من القيمة والدورية، وأضف خططاً إضافية (باص، وجبات...) إن لزم.
3. **فواتير الشهر**: المالية → الفواتير → «إصدار فواتير الشهر» — تصدر فاتورة لكل تسجيل فعّال مرتبط بخطة (الـ cron الشهري سيتولى الأشهر القادمة تلقائياً).
4. **حسابات المعلمات والمحاسِبة**: صفحة `/staff` → إضافة موظف (الدور: معلمة أو محاسِبة) وتسليم بيانات الدخول.
5. **رموز أولياء الأمور**: أرسلها عبر واتساب (من مخرجات الأمر أعلاه، أو من بطاقة الرمز في صفحة كل طالب حيث يوجد زر «إرسال عبر واتساب» جاهز).
6. **جولة سريعة مع المديرة**: تسجيل حضور تجريبي + تقييم تجريبي + إعلان ترحيبي، وتثبيت التطبيق على هاتفها.

## قائمة التحقق — ٤٥ دقيقة

| الوقت | الخطوة | تمّت؟ |
|---|---|---|
| 0–10 د | مراجعة بيانات الحضانة المستلمة (الصفوف، الطلاب، القسط) وتحويلها إلى JSON | ☐ |
| 10–15 د | تشغيل `admin:onboardNursery` وحفظ الـ `nurseryId` وقائمة الرموز | ☐ |
| 15–20 د | دخول المديرة على `/login` والتحقق من الصفوف والطلاب معها | ☐ |
| 20–25 د | رفع الشعار + مراجعة خطط الرسوم | ☐ |
| 25–30 د | «إصدار فواتير الشهر» والتحقق من صفحة المالية | ☐ |
| 30–35 د | إنشاء حسابات المعلمات/المحاسِبة وتسليمها | ☐ |
| 35–40 د | إرسال رموز أولياء الأمور عبر واتساب + تجربة رمز واحد على `/portal` | ☐ |
| 40–45 د | جولة تدريبية: حضور + تقييم + إعلان ترحيبي + تثبيت التطبيق | ☐ |

انتهى — الحضانة تعمل، وأول ولي أمر يرى يوم طفله في نفس الجلسة.
